# ⌨️ Library System
---------------------------

A simple Java project demonstrating Object-Oriented Programming through a basic library management system.  
It includes publications, books, magazines, and a lending flow with custom exceptions.

## 📁 Structure
```
src
├── Main.java
├── model
│    ├── Publication.java
│    ├── Book.java
│    ├── Magazine.java
├── exceptions
│    └── ResourceNotAvailableException.java
└── loan
     └── Prestable.java
```

## ⚙️ Features
- Base abstract class for publications  
- Specialized types: Book and Magazine  
- Interface for loanable items  
- Custom exception for unavailable resources  

## 🧩 Purpose
Practice clean OOP design, inheritance, interfaces, and error handling.
